# Dependency triage (INT-46)

The Dependabot alerts as of 2026-11-23, each traced to the package that pulls it in and checked
against how DefiMind uses it. None was reachable in DefiMind as it runs. On 2026-11-24 the high one
and minimatch were fixed anyway. The others have no fix inside the range their parent accepts, so
each records why it stays and waits for the parent to update. The production image (`packages/guard-core/Dockerfile`) installs with
`--ignore-scripts`, and `pnpm-workspace.yaml` lets only esbuild and better-sqlite3 run install
scripts.

Dependabot's PR #1 (esbuild 0.25.12 → 0.28.1 in the panel and onchain) is not a security fix. 0.25.12
is already past the advisory. It is superseded by this triage. A version bump can come later on its
own, together with a check that the signing page's published SHA256SUMS change as expected.

Re-check on every lockfile change that adds a build script, and when `@solana/spl-token`, jayson or
drizzle-kit release a version that drops these dependencies.
