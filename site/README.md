# DefiMind website

A single-file landing page (`index.html`) for DefiMind. No build step: every style and script is
inline, so any static host can serve the file as-is.

The copy is written for people who have never heard of multisigs or x402: technical terms are
explained in line, and every claim comes from [`/SPEC.md`](../SPEC.md). DefiMind is self-hosted:
each owner runs their own.

To preview locally, open `index.html` in a browser.
